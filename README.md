# Dwight Angelo Decena — Portfolio

Mobile & Web Application Developer portfolio built with React, Tailwind CSS and lucide-react.

- `site/` — Vite + React app (the deployable portfolio)
- `Portfolio.jsx` — the single-file component
- `portfolio.html` — standalone version that runs from CDNs

## Run locally

```bash
cd site
npm install
npm run dev
```

## Deploy

Import the repo on Vercel and set **Root Directory** to `site`.
